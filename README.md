# HR Analytics Dashboard

## Objective
To analyze employee data and understand workforce trends, attrition patterns, and employee satisfaction.

## Tools Used
- Microsoft Excel
- Power BI

## Dashboard Includes
- Total Employees
- Attrition Count
- Average Age
- Average Monthly Income
- Department Wise Attrition
- Gender Distribution
- Job Satisfaction Analysis
- Age Group Analysis

## Key Insights
- Identified departments with higher attrition
- Analyzed employee satisfaction levels
- Compared workforce distribution across departments

## Skills Used
- Power BI Dashboarding
- Data Visualization
- Data Cleaning
- Business Analytics
